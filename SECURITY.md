# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/benixon/benchspec/security/advisories/new). This routes the report directly to the maintainers and lets us coordinate a fix and disclosure timeline before the issue becomes public.

Include where helpful:

- A description of the issue and the assumed threat model
- Steps to reproduce (a minimal failing example is ideal)
- The benchspec version (`benchspec --version` or `git rev-parse HEAD`)
- Any suggested fix

We aim to acknowledge reports within 7 days.

## Supported Versions

benchspec is pre-1.0. Only the latest `main` branch receives security fixes; there are no maintained release branches yet.
